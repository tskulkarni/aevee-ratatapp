# RAAT SDK

## Overview

If you're new to the SDK, check out the [Technical Overview](http://roonlabs.com/raat/techoverview).

This repository is read-only, so before you start working, you will probably want to create a private fork and 
check out the fork. That way, you'll have a place to keep track of your changes, and a clean 
way to propose changes to the core components if needed.

After you do this, you will be isolated from SDK updates from Roon until you manually pull from upstream. This is good, 
because it keeps your environment stable, but it is bad because you won't be getting bug-fixes. When you're ready to pull
from upstream, [see this document for information on how to do it](https://help.github.com/articles/syncing-a-fork/).

If you are new to git or distributed version control, [check out this page](https://help.github.com/articles/good-resources-for-learning-git-and-github/).

API Reference documentation can be generated by running 'doxygen' in the repository root. This requires that [Doxygen](http://www.doxygen.nl) be installed on your machine.  

## Repository layout:

* `raat/` the core RAAT library
* `rcore/` Roon core utilities library
* `plugins/` RAAT plugin implementations provided by Roon
* `raatool/` A debug tool for interacting with RAAT devices. It can perform discovery, dump logs, etc.
* `raat_app/` A RAAT device implementation driven by a JSON config file
* `external/` open source dependencies
* `samples/` Sample code 
* `samples/null/` Sample code for a RAAT device that sends audio data to /dev/null and simulates a volume control
* `custom/` partner-specific implementaiton code should go in the custom/ directory. Roon will not touch the contents of this folder.
